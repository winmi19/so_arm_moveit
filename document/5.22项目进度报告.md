## 一、项目整体框架

```
                        LeRobot SO101 智能分拣机器人

    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │  感知层   │ →  │  决策层   │ →  │  规划层   │ →  │  控制层   │ →  │  执行层   │
    │ (视觉)   │    │ (FSM)    │    │ (MoveIt2) │    │ (ros2_ctrl)│  │ (舵机)   │
    └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
         │               │               │               │               │
    RealSense D405  状态机引擎    IK求解+轨迹      joint_traj    STS3215 ×6
    YOLOv8 + HSV    PICK/PLACE      规划          Action接口     串口驱动
```

### 核心思路

机器人通过 **RealSense 深度相机** 看见桌面上的彩色物体，**YOLOv8** 检测物体位置和类别，**HSV 颜色分类器** 判断颜色，然后 **FSM 状态机** 决定抓取/放置顺序，**MoveIt2** 计算机械臂运动轨迹，最终通过 **ros2_control** 驱动 6 个舵机执行抓放动作。

### 双轨运行

| 模式 | 用途 | 相机 | 执行 |
|------|------|------|------|
| **仿真** | 算法开发/测试 | Gazebo 虚拟相机 | Gazebo 物理引擎 |
| **真机** | 实际比赛 | RealSense D405 | STS3215 舵机 |

## 四、数据流与话题关系

```
话题                           类型                          流向
──────────────────────────────────────────────────────────────────────

[相机 → 视觉]
/camera/camera/color/image_raw      Image (BGR8, 640×480)     → detector_node
                                   → classifier_node
/camera/camera/aligned_depth_       Image (16UC1, 640×480)    → classifier_node
  to_color/image_raw

[视觉内部]
/vision/detections                  VisionDetection            detector → classifier

[视觉 → 决策]
/vision/classified                  VisionDetection            classifier → fsm_node

[决策 → 控制]
/arm_controller/                    FollowJointTrajectory     fsm_node → 机械臂
  follow_joint_trajectory           (Action)
/gripper_controller/                FollowJointTrajectory     fsm_node → 夹爪
  follow_joint_trajectory           (Action)

[控制 → 执行]
/joint_states                       JointState                 motor_bridge → ros2_control

[系统]
/tf, /tf_static                     TFMessage                  robot_state_publisher
/robot_description                  String                     URDF 发布
```

### VisionDetection 消息结构

```
string  object_class    # 物体类别: "bottle", "can", "box"
string  color           # 颜色: "red", "blue", "green"
float32 x_pixel         # 检测框像素 X
float32 y_pixel         # 检测框像素 Y
float32 depth           # 深度值 (米)
float32 confidence      # 置信度 [0, 1]
```

## 六、FSM 状态机流程

```
          收到 /vision/classified
                 │
                 ▼
    ┌──────────────────────┐
    │       IDLE           │  等待检测结果
    └─────────┬────────────┘
              │ 检测到物体 + 颜色
              ▼
    ┌──────────────────────┐
    │       DETECT         │  查表: 颜色→放置区坐标
    └─────────┬────────────┘
              │
              ▼
    ┌──────────────────────┐
    │       PICK           │  张开夹爪 → 预抓取位 → 下降 → 闭合 → 抬起
    └─────────┬────────────┘
              │
              ▼
    ┌──────────────────────┐
    │       PLACE          │  移动到放置区 → 下降 → 张开释放 → 抬起
    └─────────┬────────────┘
              │
              ▼
    ┌──────────────────────┐
    │       RETURN         │  回到初始位
    └─────────┬────────────┘
              │
              └──→ IDLE (等待下一个物体)
```
