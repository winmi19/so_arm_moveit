## 一、项目整体框架

```
                  LeRobot SO101 医疗物品分拣机器人

    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │  感知层   │ →  │  决策层   │ →  │  规划层   │ →  │  控制层   │ →  │  执行层   │
    │ (视觉)   │    │ (FSM)    │    │ (MoveIt2) │    │ (ros2_ctrl)│  │ (舵机)   │
    └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
         │               │               │               │               │
    RealSense D405  状态机引擎    IK求解+轨迹      joint_traj    STS3215 ×6
    YOLOv8         PICK/PLACE      规划          Action接口     串口驱动
    深度增强        按类分拣
    手眼标定 ✅
```

### 核心思路

在大盒子中放置 3 种医疗物品：**注射器、玻璃瓶、棉球**。机械臂通过 **RealSense 深度相机** 观察，**YOLOv8** 检测物体类型和像素位置，**深度增强节点** 补全深度值，经 **手眼标定矩阵** 转为基座 3D 坐标，**FSM 状态机** 按物体类型查表决定放入哪个彩色盒子，**MoveIt2** 规划轨迹，**ros2_control** 驱动舵机完成抓放。

### 双轨运行

| 模式 | 用途 | 相机 | 执行 |
|------|------|------|------|
| **仿真** | 算法开发/测试 | Gazebo 虚拟相机 | Gazebo 物理引擎 |
| **真机** | 实际比赛 | RealSense D405 | STS3215 舵机 |

| 6 | `ros2 launch lerobot_vision vision_pipeline.launch.py` | YOLO 检测 + 深度增强 |
| 7 | `ros2 launch lerobot_decision decision_fsm.launch.py` | FSM 决策 (按物体类型分拣) |

> 终端 5/6 顺序可互换，无依赖关系。
>
> 终端 5 是**一次性操作**：标定完成后只跑这一次。如果想永久化，将其加入终端 2 的 launch 文件中。
>
> 手眼标定启动（仅首次或相机支架重新安装时需要）：
> ```bash
> ros2 launch lerobot_vision handeye_calibrate.launch.py marker_size:=0.1037
> ```

## 六、FSM 状态机流程

```
          收到 /vision/classified
                 │
                 ▼
    ┌──────────────────────┐
    │       IDLE           │  等待检测结果
    └─────────┬────────────┘
              │ 检测到物体 + 颜色
              ▼
    ┌──────────────────────┐
    │       DETECT         │  查表: 颜色→放置区坐标
    └─────────┬────────────┘
              │
              ▼
    ┌──────────────────────┐
    │       PICK           │  张开夹爪 → 预抓取位 → 下降 → 闭合 → 抬起
    └─────────┬────────────┘
              │
              ▼
    ┌──────────────────────┐
    │       PLACE          │  移动到放置区 → 下降 → 张开释放 → 抬起
    └─────────┬────────────┘
              │
              ▼
    ┌──────────────────────┐
    │       RETURN         │  回到初始位
    └─────────┬────────────┘
              │
              └──→ IDLE (等待下一个物体)
```
