# 项目全貌：LeRobot SO101 医疗物品分拣机械臂

你在做一个**比赛项目**：用 SO-ARM101 六自由度机械臂（6× Feetech STS3215 舵机）+ RealSense D405 深度相机，识别桌上的医疗物品（注射器/玻璃瓶/棉球），按类型自动抓取并分拣到不同盒子。文档记录了 5.20 → 5.27 约一周的密集开发过程。

---

## 一、技术框架：五层架构 + 双轨运行

```
感知层 ──→ 决策层 ──→ 规划层 ──→ 控制层 ──→ 执行层
RealSense    FSM状态机   MoveIt2     ros2_control  STS3215×6
YOLOv8       按类查表    KDL IK      两个控制器     串口驱动
手眼标定      坐标转换
```

- **系统基座**：ROS2 Humble，两个工作空间
  - `lerobot_ws`（主仓库）：description(URDF) / controller / moveit / vision / decision / interfaces 六个包
  - `second_repo/lerobot_ros2`：`so101_hw_interface`，核心是 `motor_bridge.py` 串口驱动
- **仿真/真机双轨**：同一套上层代码，通过换 ros2_control 硬件插件切换
  - 仿真：`GazeboSimSystem`（Gazebo 内嵌 ros2_control）
  - 真机：`TopicBasedSystem` → 话题 `/so101_follower/joint_commands` → motor_bridge → 串口 `/dev/ttyACM0`
- 真机全链路要开 **7 个终端**：串口驱动 → 控制器 → MoveIt2 → 相机 → 手眼TF → 视觉管线 → FSM

## 二、各层技术细节

**执行层（95%）**：motor_bridge 以 50Hz `sync_read` 读舵机 12bit 磁编码器（0-4095），套公式 `(raw - homing_offset) × 2π/4096` 转弧度发布。你在《数据流详解》里把"编码器→RViz"整条链路吃透了，解决了 5 个标定对齐问题（零位偏 90°、夹爪 homing 要用 `range_min+111` 而非中值、关节 5 方向反需 `direction:-1` 等）。

**规划层（90%）**：MoveIt2 + KDL 运动学，RViz 拖拽 Plan/Execute 可用。arm(关节1-5) 和 gripper(关节6) 两个 planning group，走 `FollowJointTrajectory` Action。

**感知层（78%）**：
- YOLOv8 检测节点（目前预训练权重，待微调 3 类医疗物品）
- 深度增强节点：原本是 HSV 颜色分类，5.25 架构重构后**删除颜色分类**，改为纯深度采样
- **手眼标定（5.25 最大里程碑）**：eye-in-hand，easy_handeye2 + **自建 `aruco_detector.py`**（因 aruco_ros 无 dictionary 参数、aruco_opencv TF 静默失败，干脆自己用 `cv2.solvePnP` + TransformBroadcaster 实现），12 组样本解出 T_cam2ee

**决策层（65%）**：FSM 状态机 `IDLE→DETECT→PICK→PLACE→RETURN`，物体类型查表定放置区，像素→基座 3D 坐标转换。

## 三、最有价值的部分：踩坑后的最终方案

教科书路线走不通，你最后落地的方案（5.27 定稿）：

```
YOLO检测 → 桌面区中位深度 → 射线-平面求交(XY) → compute_ik → arm_controller
          ↑避开夹爪采样      ↑Z固定table_z=0.14   ↑跳过MoveGroup
```

三个关键工程决策：
1. **放弃 MoveGroup 规划**——位置约束规划全部返回 99999，改直接调 `compute_ik` 服务算关节角发给控制器
2. **放弃 depth→Z 直接映射**——眼在手上时相机 Roll 角把 Z 误差放大到 0.07~0.77 乱跳，改为从相机发射线与桌面平面（Z=0.14）求交，只用几何算 XY
3. **深度不在检测点采样**——眼在手上必然拍到夹爪（采到 0.066m 而非桌面 0.16m），改取图像下半部桌面区中位深度

加上人工补偿（`grasp_x/y/z` offset 修 5cm 系统偏差）、夹爪闭合时间 1s→3s 等参数，共记录了 **16 个坑**的完整因果链。
