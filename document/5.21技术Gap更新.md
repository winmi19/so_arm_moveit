### VisionDetection (`lerobot_interfaces/msg/VisionDetection.msg`)

```
string object_class      # 物体类别: "bottle", "can", "box"
string color             # 颜色: "red", "blue", "green", "unknown"
float32 x_pixel          # 检测框中心像素X坐标
float32 y_pixel          # 检测框中心像素Y坐标
float32 depth            # 深度值 (米), 无深度相机时为0
float32 confidence       # 检测置信度 [0.0, 1.0]
```

## 七、数据流完整路径

```
RealSense D405
    │
    ├── /camera/camera/color/image_raw (640x480 BGR8, 30Hz)
    │       │
    │       ├──► detector_node (YOLOv8 推理)
    │       │       │
    │       │       └──► /vision/detections
    │       │               object_class, confidence, x_pixel, y_pixel
    │       │
    │       └──► classifier_node (缓存为 _latest_color)
    │
    ├── /camera/camera/aligned_depth_to_color/image_raw (16UC1 mm, 30Hz)
    │       │
    │       └──► classifier_node (缓存为 _latest_depth)
    │
    └── /camera/camera/color/camera_info
            │
            └──► (待用于 pixel_to_world() 坐标转换)

classifier_node 内部:
    /vision/detections msg 到达
        → 从 _latest_color 裁剪 128×128 ROI
        → HSV 颜色分类 (pixel-wise mask 占比)
        → 从 _latest_depth 采样 7×7 窗口取均值
        → ×0.001 (mm→m)
        → 发布 /vision/classified (object_class + color + depth)

fsm_node (待集成):
    /vision/classified msg 到达
        → coordinate_transform.pixel_to_robot_plane() (⚠️ 占位值)
        → FSM: IDLE → DETECT → PICK → PLACE → RETURN → IDLE
        → 查表: color → place_zone_xyz
        → Action: 调 gripper_controller (✅) / MoveIt2 (⚠️ 桩函数)
```

## 八、5.21 发现的 Bug 及修复

### Bug #1: classifier_node 启动崩溃

**现象:**
```
TypeError: The given value is not one of the allowed types '{}'.
```

**原因:** ROS2 Humble `declare_parameter()` 不支持 Python dict 作为默认值。

**修复:** `classifier_node.py:35` — 移除 `declare_parameter('hsv_ranges', {})`, 直接使用 `ColorClassifier()` 默认 HSV 值。

### Bug #2: detector.py `np` 未导入

**现象:**
```
NameError: name 'np' is not defined
```

**原因:** `_detect_onnx()` 方法内使用了 `np.full()`, `np.transpose()`, `np.expand_dims()` 但未 `import numpy as np`。

**修复:** `detector.py:95` — 在 `_detect_onnx()` 方法开头添加 `import numpy as np`。

### Bug #3: detector 无模型时走错分支

**现象:**
```
AttributeError: 'YOLODetector' object has no attribute '_ort_session'
```

**原因:** `detect()` 方法中 `self.model is None` 时直接调用 `_detect_onnx()`, 但 `_ort_session` 仅在 `_load_onnx()` 中创建。当模型文件不存在时, `load()` 从未执行, 导致 `_ort_session` 不存在。

**修复:** `detector.py:65` — 改为 `elif hasattr(self, '_ort_session') and self._ort_session is not None`, 否则返回空列表。

### Bug #4: model_path 空格截断

**现象:**
```
ros2 pkg prefix: error: the following arguments are required: package_name
lerobot_vision: command not found
模型文件不存在: /share/lerobot_vision/models/yolov8n.pt
```

**原因:** shell 命令 `$(ros2 pkg prefix lerobot_vision)` 在 launch 命令中换行导致空格被解释为参数分隔。

**修复:** 使用引号包裹: `"$(ros2 pkg prefix lerobot_vision)/share/lerobot_vision/models/yolov8n.pt"`

### Bug #5: models/ 目录未安装

**原因:** `setup.py` 的 `data_files` 未包含 `models/yolov8n.pt`。

**修复:** `setup.py` — 在 data_files 中添加 `('share/' + package_name + '/models', ['models/yolov8n.pt'])`。

### Bug #6: colcon build 失败 (setuptools/packaging 冲突) ⚠️ 未修复

**现象:**
```
TypeError: canonicalize_version() got an unexpected keyword argument 'strip_trailing_zero'
```

**原因:** setuptools 79.0.1 调用 packaging 的 `canonicalize_version(version, strip_trailing_zero=False)`, 但该参数在较新版本 packaging 中已被移除。

**影响:** 无法通过 colcon 编译代码修复, 上面 Bug #1~#5 的修复在源码中已改但未部署到 install 目录。
